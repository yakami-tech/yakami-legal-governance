# ⚖️ YAKAMI Governance Protocol

## 📌 Visão Geral
Este repositório contém o **MVP do Protocolo de Governança** da YAKAMI TECH. O foco é a criação de um "Cartório Digital de dados Ambientais da Amazonia" para validação de dados ambientais coletados na Amazônia, garantindo prova de anterioridade e integridade para ativos reais (RWA).

## 🚀 Implementação Técnica
- **Linguagem:** Solidity ^0.8.20
- **Segurança:** Custom Errors para otimização de gas e Modifiers para controle de acesso.
- **Rede:** Ethereum Sepolia Testnet.
